# PCBWay

Builds a PCBWay-ready ZIP of the board open in PCBJam's PCB editor: Gerbers, drill files, an IPC-356 netlist, and PCBWay's BOM and placement CSVs. PCBJam generates the files on its servers from the saved project; the plugin never sees them. Download the ZIP and upload it on PCBWay's online quote page.

Source: https://github.com/PCBJam/pcbjam-pcbway-plugin (MIT).
