# PCBWay Export

Builds a PCBWay-ready ZIP of the board open in PCBJam's PCB editor: Gerbers, drill files, an IPC-356 netlist, and PCBWay's BOM and placement CSVs. PCBJam generates the files on its servers from the saved project; the plugin never sees them. Send it to PCBWay for a quote, or download the ZIP and upload it on PCBWay's online quote page.

Source: https://github.com/PCBJam/pcbjam-pcbway-plugin (MIT; the CSV rules are ported from PCBWay's MIT-licensed KiCad plugin, see LICENSE.txt).
